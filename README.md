# 📘 Travel Explorer

A modern and responsive **Travel Explorer Web App** built using **HTML, CSS, JavaScript**, and the **REST Countries API**.
Users can search for any country and instantly view important travel-related details like flag, capital, region, population, currency, language, and timezone.

---

## 🌍 Features

* 🔎 Search any country
* 🏳️ Display country flag
* 🏙️ View capital city
* 🌎 Region information
* 👨‍👩‍👧 Population details
* 💱 Currency information
* 🗣️ Official language
* ⏰ Timezone details
* 📱 Responsive modern UI
* 🎨 Beautiful gradient design

---

## 🛠️ Technologies Used

* HTML5
* CSS3

* Google Fonts

---

## 🔗 API Used

### REST Countries API

```bash
https://restcountries.com/v3.1/name/{country}
```

Example:

```bash
https://restcountries.com/v3.1/name/india
```
